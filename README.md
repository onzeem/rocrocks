# ROC Rocks Budgeting

## Inspiration

This project was designed for any people who are looking to spend their money in a smarter way. 

## What it does
Organizes your budget broken down into spending categories, keeps track of transactions, shows you your savings progress, and overall keeps you informed of your spending habits and status.

## Challenges we ran into
Since we split up and developed the front and back ends separately, we ran into some issues when connecting the two, making sure the front end was using real data instead of placeholder values for visuals. There were some instances where one teammate's code would be functioning as intended the other's wasn't and vice versca, despite how many pushes and pulls we made in git. We were successfully naviagted these errors and are now in sync!

## Next steps
The front end of our app has some aspects that don't yet have a backend, like the ability to upload a receipt and log it automatically in your spending. Tackling something like this would be a great way to take the features of our web app to the next level.

## Accomplishment
We were able to connect the front end to a database we created in SQL, which neither of us had done before!
